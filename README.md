# Bellingsfield Trades Directory

Static GitHub Pages site containing 73 trade/service contacts across 16 categories.

## Publish on GitHub Pages

1. In GitHub, create a new **public** repository. A name such as `bellingsfield-trades` works well.
2. Upload these four site files to the root of the repository:
   - `index.html`
   - `styles.css`
   - `app.js`
   - `data.js`
3. Commit the files.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then Save.
7. GitHub will display the site's public Pages URL.

## Updating the directory

The contacts live in `data.js`. Each entry contains category, name, displayed phone number and the international digits used by the Call/WhatsApp links.

## Privacy

Publishing with GitHub Pages makes the repository and contact list publicly accessible on the internet. If the directory should only be available to Bellingsfield residents, do not use a normal public GitHub Pages repository without considering that implication.
